# jsonv v1.2.4 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

A CI-configuration release: the package is unchanged. The published files are the same as v1.2.3 apart from the version number, and the parser is unchanged.

---

## 🔧 CI & tooling

- `.github/dependabot.yml` takes the npm groups from the CLDMV/.github v4.47.0 template. The CLDMV dev tools (`@cldmv/vitest-runner`, `@cldmv/fix-headers`, `@cldmv/configs`, the jsonv packages) now arrive in one `cldmv-dev` PR, runtime `@cldmv/*` dependencies in a separate `cldmv` group, and the generic patch and minor groups exclude every named family, so each package lands in exactly one group ([#141](https://github.com/CLDMV/jsonv/pull/141), [CLDMV/.github#593](https://github.com/CLDMV/.github/issues/593)).
