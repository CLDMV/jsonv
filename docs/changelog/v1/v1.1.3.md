# @cldmv/jsonv v1.1.3 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Version 1.1.3 is a CI-only release with no runtime code changes. It corrects v1.1.2's required-check fix so in-repo PRs report their status from a job that actually runs, and bumps the ESLint plugin used by the lint config.

---

## 🔧 CI & tooling

- **In-repo PR mirror job runs instead of being skipped** ([#78](https://github.com/CLDMV/jsonv/pull/78)) — the `✅ Required PR Check` mirror now runs on the `pull_request` event for in-repo PRs and reports the CI result, rather than relying on a renamed skipped job.
