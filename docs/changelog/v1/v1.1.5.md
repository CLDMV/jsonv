# @cldmv/jsonv v1.1.5 Changelog

**Release Date**: October 2026
**Release Type**: Patch

---

## Overview

Version 1.1.5 is a dev-dependency refresh. Nothing under `src/`, `scripts/` or the published `dist/` changed, and `package.json` differs from v1.1.4 only in its `version` field: every bump below is a lockfile re-resolution inside the existing `^` ranges. Every package that changed in `package-lock.json` is a development dependency, so the published package and its consumers are unaffected.

The one change that reaches beyond a patch bump is in the test toolchain. `@cldmv/vitest-runner` 1.5.3 raises its own Node.js floor from `>=20.19.0` to `>=22.12.0` and moves to `chalk` 6, which also needs Node.js 22. The repository's CI matrix already starts at 22.12.0 (the floor `vitest` 5 runs on), so CI is not affected; running `npm test` locally now needs Node.js 22.12.0 or later.

---

## 🔧 CI & tooling

- The test runner `@cldmv/vitest-runner` 1.5.3 adds `require()` checks for its own CommonJS entry and fails with a clear `ERR_REQUIRE_ESM` message on Node.js without `require(esm)`. It affects only how the runner loads, not how this repository's tests run: `npm test` (Vitest, then the `node:test` CommonJS entry checks) and `npm run build:ci` pass on the merged `next` branch.
- `@cldmv/eslint-plugin-jsonv` 1.0.15 only updates that plugin's own expectations for `@cldmv/jsonv` 1.1.1 behavior; the lint rules this repository uses are unchanged.

## 🔧 Dependencies

All development-only. The lockfile entries are `dev`; none is a runtime or peer dependency, and `package.json` ranges are untouched.

- `@cldmv/vitest-runner` 1.5.1 → 1.5.3 ([#92](https://github.com/CLDMV/jsonv/pull/92)). Its `engines.node` moves from `>=20.19.0` to `>=22.12.0`, and its `chalk` dependency moves from `^5.4.1` to `^6.0.1`. In the lockfile that replaces the runner's nested `chalk` 5.6.2 with a top-level `chalk` 6.0.1 (`engines.node` `>=22`).
- `@cldmv/eslint-plugin-jsonv` 1.0.13 → 1.0.15 ([#92](https://github.com/CLDMV/jsonv/pull/92)). Its `engines.node` (`^20.19.0 || ^22.13.0 || >=24`) is unchanged.
- `@types/node` 26.6.3 → 26.6.4 ([#92](https://github.com/CLDMV/jsonv/pull/92)).
- `vitest` 5.0.2 → 5.0.3, with `@vitest/coverage-v8`, `@vitest/mocker` and `@vitest/spy` at 5.0.3 ([#87](https://github.com/CLDMV/jsonv/pull/87)). `vitest` 5.0.3 pins its `why-is-node-running` dependency to exactly 3.2.1, so that package resolves one patch version lower than before (3.2.2 → 3.2.1). `vitest` still requires Node.js `^22.12.0 || ^24.0.0 || >=26.0.0`.
- `eslint` 10.11.0 → 10.12.0 ([#88](https://github.com/CLDMV/jsonv/pull/88)).
- `globals` 17.12.0 → 17.13.0 ([#90](https://github.com/CLDMV/jsonv/pull/90)).
- Transitive tooling that moved with the Vitest update: `vite` 8.3.1 → 8.3.2, `rolldown` 1.2.11 → 1.2.12 (and its platform bindings) and `@oxc-project/types` 0.151.0 → 0.152.0.

## Upgrade notes

- No breaking changes, and no runtime code changed. It is a drop-in replacement for v1.1.4.
- The package's `engines` field (`>=18.0.0`) and the Node.js requirement for `require()` (^20.19.0 or >=22.12.0) are unchanged.
- For contributors: running the test suite locally needs Node.js 22.12.0 or later, the same floor `vitest` 5 has and the CI matrix already uses.
