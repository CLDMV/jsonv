# `@cldmv/jsonv` v1.2.1 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `release/1.2.1`

---

## Overview

jsonv goes back to `engines.node` `>=18.0.0`. v1.2.0 raised it to `>=22.22.0`, the version the development toolchain needs, but jsonv has no dependencies and nothing in the package needs more than Node.js 18 for `import`. The toolchain floor moves to npm's `devEngines`, where it only applies to working on this repository.

The parser and every public specifier are unchanged from v1.2.0.

---

## 📦 Requirements

### `engines.node` is `>=18.0.0` again ([#118](https://github.com/CLDMV/jsonv/pull/118))

`engines.node` drops from `>=22.22.0` to `>=18.0.0`, the range v1.1.5 and earlier declared. `import` works from Node.js 18.0.0, and jsonv still runs in browsers. `require()` loads the ESM build through Node's `require(esm)`, so it needs Node.js `^20.19.0` or `>=22.13.0`; the `ERR_REQUIRE_ESM` message that every CommonJS wrapper throws on a Node.js without `require(esm)` now names that range instead of `>=22.22.0`.

Developing the package still needs Node.js 22.22.0 or later. That floor is now declared in `devEngines` (`runtime` `node` `>=22.22.0`, `onFail: "error"`), so npm enforces it in a checkout of this repository and never for consumers installing the package.

## 🔧 CI & tooling

- tsup's target is now `["es2022", "node18"]` instead of `es2022`, so the build emits only syntax that both browsers at the ES2022 level and Node.js 18 support ([#118](https://github.com/CLDMV/jsonv/pull/118)).
- The CI and publish matrices still start at Node.js 22.22.0; the `min_node_version` descriptions now say it is the dev toolchain floor and should match `devEngines`, not `engines` ([#118](https://github.com/CLDMV/jsonv/pull/118)).

## 🧪 Tests

- `tests/cjs/entry.test.cjs` checks for the new `^20.19.0 or >=22.13.0` guard message ([#118](https://github.com/CLDMV/jsonv/pull/118)).

## 📚 Documentation

- The README requirements and `docs/versioning-and-exports.md` list Node.js 18.0.0 for `import`, `^20.19.0` or `>=22.13.0` for `require()`, and the 22.22.0 `devEngines` floor for development ([#118](https://github.com/CLDMV/jsonv/pull/118)).
- The v1.2.0 notes no longer call its Node.js floor "a real requirement change" ([#117](https://github.com/CLDMV/jsonv/pull/117)).
