# jsonv v1.2.3 Changelog

**Release Date**: November 2026
**Release Type**: Patch
**Branch**: `next` → `master`

---

## Overview

A packaging and tooling release with no parser changes. The CommonJS entry is now the generic shim shared by the CLDMV libraries, and `require("@cldmv/jsonv")` returns the same module object as before. The test suite now also runs against the built `dist/`, CI cancels superseded runs, and the dev toolchain is refreshed.

---

## 📦 Packaging

### The CommonJS entry is the generic shim ([#137](https://github.com/CLDMV/jsonv/pull/137))

`src/index.cjs`, published as `dist/index.cjs`, is now the shim every CLDMV library ships: a Node.js version guard, then `require("./index.mjs")`. jsonv exports several values, so `require("@cldmv/jsonv")` returns the module object with every ESM export, exactly as before. The CJS test pins that shape.

---

## 🧪 Tests

### The suite runs against the build too ([#125](https://github.com/CLDMV/jsonv/pull/125))

The tests now import the package by name instead of by `src/` path, so the new `test:dist` script builds the package and runs the whole suite against `dist/` with `--mode=dist`. A new resolve test checks that each mode loaded the tree it was meant to. `npm test` and `ci:coverage` run it.

---

## 🔧 CI & tooling

- `ci.yml` adopts the CLDMV/.github v4.46.0 concurrency block, so superseded runs on `next`, `hotfixes` and the release PR are cancelled and only release pushes always finish ([#138](https://github.com/CLDMV/jsonv/pull/138), fixes [#136](https://github.com/CLDMV/jsonv/issues/136)).
- `ci.yml` is synced with the v4.43.0 template ([#134](https://github.com/CLDMV/jsonv/pull/134)).
- The `sync-release-notes.yml` companion workflow syncs release bodies from these changelog files and creates missing version tags ([#132](https://github.com/CLDMV/jsonv/pull/132)).
